

## 📖 Milestone-2 Overview

This repository contains a complete collection of Oracle SQL and PL/SQL laboratory assignments, database exercises, and a mini project. It covers fundamental to advanced database concepts including Data Definition Language (DDL), Data Manipulation Language (DML), Subqueries, PL/SQL Programming, and SQL Mini Project implementation.

The repository is intended for students, beginners, and database enthusiasts who want hands-on practice with Oracle SQL and PL/SQL through real-world exercises and practical examples.
