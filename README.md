
## 📖 Milestone-1 Overview

This repository contains a comprehensive collection of Oracle SQL practice exercises completed as part of database management and SQL learning. The assignments cover fundamental to intermediate SQL concepts, including data retrieval, filtering, sorting, joins, aggregate functions, single-row functions, set operations, and database normalization.

Each exercise includes SQL queries along with sample outputs, providing practical experience in writing efficient SQL statements and understanding relational database concepts. The repository is designed as a learning resource for students, beginners, and anyone preparing for SQL interviews or database-related assessments.
